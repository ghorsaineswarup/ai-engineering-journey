# Expense Tracker

A simple command-line tool to track expenses and calculate totals by category.

## What it does
- Stores individual expenses (amount, category, date, description)
- Validates data — rejects negative amounts, empty categories, empty dates
- Adds multiple expenses to a tracker
- Calculates total money spent
- Calculates total spent per category

## What I practiced
- Object-Oriented Programming (classes, __init__, self)
- Working with lists of objects
- Looping and accumulating totals
- Error handling: raising custom errors with `raise ValueError(...)`
- Catching errors gracefully with try/except so the program doesn't crash
